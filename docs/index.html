Install in minutes

MelonLoader stack. No wizard required.

  1. Install MelonLoader for BONELAB.
  2. Install BoneLib and LabFusion.
  3. Drop FusOpt.dll into BONELAB/Mods (or install via Thunderstore).
  4. Launch → BoneMenu → FusOpt → Crowded preset.

Ship frames. Keep the lobby.
